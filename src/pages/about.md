# About

I'm a technical writer based in China. I write user and developer documentation
for open source software, using a docs as code workflow alongside distributed,
multinational teams.

I write user and developer documentation for open source software. My work has
covered wallet apps, a hardware wallet, messaging applications, and a
distributed-systems stack covering blockchain, storage, and messaging protocols,
for audiences ranging from first-time users to developers and node operators.

## How I work

I structure documentation loosely around the Diátaxis model across four content
types: procedures, concepts, references, and troubleshooting.

Before writing, I do a task analysis: I learn the feature, identify the tasks
users can complete with it, and decide which documents are needed and of what
type.

For user documentation, design files are my primary source. I also test the
product myself and confirm details with subject matter experts. For developer
documentation, engineers usually provide a written draft, which I restructure
and edit; I then test against the product and go back to the engineers for
anything missing.

I use Claude Code to configure CI tooling and to produce first drafts that align
with my templates and style guide.
